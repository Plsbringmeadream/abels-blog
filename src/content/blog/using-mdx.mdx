## 一开始：反复安装卸载的历程

说实话，我和 OpenClaw 的相处并不顺畅。从第一次接触到现在，中间经历了好几轮安装→卸载→重新安装。有时是配置问题，有时是不知道怎么用。但就是这么折腾了几轮，慢慢摸清楚了它的逢辑。

Honestly, my relationship with OpenClaw wasn't smooth at first. I went through several rounds of install → uninstall → reinstall. Sometimes it was config issues, sometimes I just didn't know how to use it. But working through those cycles is exactly how I finally got a feel for it.

---

## 已掌握的技能 / Skills I've Picked Up

### 1. 安装与更新

目前已经能够独立完成 OpenClaw 的安装和更新到最新版本。包括处理安装中常见的依赖和环境问题。

I can now independently install and update OpenClaw to the latest version, including handling common dependency and environment issues during setup.

### 2. 自然语言创建和下载 Skill

这个功能让我很惊喜。只需要用自然语言描述想要的功能， OpenClaw 就可以帮你创建一个对应的 Skill，也可以直接从社区下载别人做好的 Skill。不需要写一行代码。

This blew me away. Just describe what you want in plain language, and OpenClaw creates a corresponding Skill — or you can download pre-made ones from the community. No coding required.

### 3. 调用不同的大语言模型

OpenClaw 支持接入多种大语言模型。我可以根据任务需求灵活切换，比如处理复杂任务用 Claude，快速下任务用其他轻量模型。

OpenClaw supports multiple LLMs. I can switch between them depending on the task — use Claude for complex reasoning, lighter models for quick jobs.

### 4. 用 Skill 自动化重复性工作

这是我目前用得最多的场景。我有一个产品报价的工作需要填写大量表格，包含图片、价格和产品详情。产品 SKU 很多，逐个手动填非常耗时。

于是我用 OpenClaw 的 UI 界面调用 Claude 模型，将产品数据输入后自动生成完整的报价表格，并直接保存到我的桌面。这个流程原来要花我大半天，现在几分钟搞定。

This is my most-used use case. I have a product quoting workflow that requires filling in tables with images, prices, and product details — and the SKU count is huge. Doing it manually ate up half my day.

Now I use OpenClaw's UI to feed product data to Claude, which auto-generates the complete quote table and saves it directly to my desktop. What used to take hours now takes minutes.

### 5. Telegram & Discord 机器人远程控制

这是我最喜欢的功能之一。我建了两个机器人：一个在 Telegram，一个在 Discord。

通过手机发一条消息，就可以远程调用电脑上的 OpenClaw 执行任何 Skill。不在电脑旁边，只要有网络，一样可以控制我的电脑完成各种任务。

One of my favorite setups. I built two bots — one on Telegram, one on Discord. Send a message from my phone, and it remotely triggers OpenClaw on my computer to run any Skill. As long as there's internet, I can control my machine from anywhere.

## 展望 / Still Exploring

OpenClaw 的功能远不止这些。我目前还在探索中，很多功能还没有完全弄明白。但已经接触到的部分就已经让我觉得这个工具非常强大。

期待后续探索更多可能性，持续建立自己的工具集，让重复性工作越来越少，将更多时间留给真正重要的事。

There's so much more to OpenClaw that I haven't figured out yet. But even what I've learned so far has already changed how I work. Looking forward to discovering more, building out my personal toolkit, and gradually eliminating the repetitive tasks that used to eat up my day.
