## 为什么是 Obsidian？

最近开始接触一个新工具——**Obsidian**。这是一款以本地 Markdown 文件为基础的笔记软件，最大的特点是所有数据都存在自己的电脑上，不依赖任何云服务。可以建立笔记之间的双向链接，形成一个个人知识网络。

I recently started exploring **Obsidian** — a local-first Markdown note-taking app where all data lives on your own machine. Its key feature is bidirectional linking between notes, letting you build a personal knowledge network over time.

---

## 创建第一个仓库 / First Vault

安装 Obsidian 后，我创建了自己的第一个 Vault（Obsidian 里称工作区间为“Vault”，本质上就是一个文件夹）。这是我知识库的起点，还是一张白纸。

After installing Obsidian, I created my first Vault — in Obsidian, a "Vault" is simply a folder on your machine. It's the starting point of my knowledge base, still a blank slate.

---

## 用 Claude Code 打地基 / Setting Up with Claude Code

光有一个空文件夹还不够，我想建立一套整齐的目录结构。于是我调用了 Claude Code，请它帮我完成初始化工作。

An empty folder wasn't enough — I wanted a clean directory structure from the start. So I brought in Claude Code to handle the initialization.

**完成了以下两件事：**

1. **建立根目录结构** — 让 Claude Code 按我的需求建立了 Vault 的顶层目录框架，包括分区、素材模板等大类
2. **创建欢迎文档** — 在根目录下建了第一个 `.md` 文件：一份欢迎文档，记录这个 Vault 的目标和使用规则

**Two things done:**

1. **Root directory structure** — Claude Code scaffolded the top-level folder layout of the Vault, including sections for categories, assets, and templates
2. **Welcome document** — Created the first `.md` file at the root: a welcome note documenting the Vault's purpose and usage guidelines

这个流程让我体会到了一个规律：**Claude Code 非常适合帮我倒掉重复性的初始化工作**。我只需说“我要什么结构”，它就把文件全建好了。

This experience highlighted something: **Claude Code is great for repetitive initialization work**. I just described the structure I wanted, and it built everything out.

## 展望 / What I Hope to Build

这只是开始。我希望随着对 Obsidian 的了解加深，能够建立一个真正属于自己的知识库——不只是打开记笔记，而是让所有内容能够相互关联、随时沉淀整理、内化成自己的思维方式。

提升方向包括：

- 掌握 Dataview 插件，实现笔记的动态查询和可视化
- 建立系统性的笔记模板（读书笔记、项目开展、日记等）
- 用 Claude Code 自动化部分内容归类整理流程
- 最终形成一个可持续运转的个人二脑

This is just the beginning. My goal is to build a real personal knowledge base — not just a note dump, but a living system where ideas connect, accumulate, and become part of how I think.

Plans ahead:

- Learn the Dataview plugin for dynamic queries and visualization
- Build systematic note templates (book notes, project logs, daily journals)
- Use Claude Code to automate parts of the organization workflow
- Ultimately create a sustainable second brain
